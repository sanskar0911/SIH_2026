# HOW TO RUN THE APPLICATION

Follow these simple steps to run the TC-INTEL India cyclone dashboard prototype locally:

## Step 1: Install Node.js
If you don't have Node.js installed, download it from [https://nodejs.org/](https://nodejs.org/) (Version 18 or higher is recommended).

## Step 2: Install Project Dependencies
Open your terminal (PowerShell, Command Prompt, or bash) in the project directory (`c:\cyclone` or cloned folder) and run:
```bash
npm install
```

## Step 3: Run the Development Server
Start the local server by running:
```bash
npm run dev
```

## Step 4: Preview in Browser
Once running, open your web browser and go to:
👉 **[http://localhost:5173/](http://localhost:5173/)**

---

### Additional Commands
- **Verify TypeScript Compile**: `npx tsc --noEmit`
- **Build for Production**: `npm run build`
- **Run Production Preview**: `npm run preview`
